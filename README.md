# NOVA · 个人官网

> 唯美简洁 · 炫酷优雅 · 强交互沉浸式单页站点

**线上地址：https://x33834.github.io/**

NOVA 是 badhope（全栈开发者 / Agent 开发者 / 开源贡献者 / AI 前沿探索者）的个人官网。
单文件自包含 HTML，无任何构建依赖，直接打开即可运行。

## 技术亮点

- **程序化霓虹公路引擎**（Canvas 2D）：穿越驾驶视角，车道流光、路灯、三层城市群、逼近曲线（越来越近但永远到达不了）
- **WebGL 星云氛围层**：fbm 分形星云 + 网格星星闪烁 + 鼠标视差，低端设备自动降级 2D 回退
- **单向流星雨**：右上→左下拖尾流星，随机冷却
- **Hash 路由多视图**：首页 / 作品 / 技能 / 关于 / 联系 / 博客 / 游戏 / 工具，页面过场动画
- **暗 / 亮 / 跟随系统** 三态主题
- **博客实时嵌入**：CSDN · 稀土掘金 iframe 自动刷新；博客园快照 + 时间戳
- **GitHub 实时探测**：运行时拉取账号数据，限流自动降级离线快照
- **离线小游戏 NOVA DRIVE**：躲避障碍收集能量，Canvas 2D 零依赖
- **开发者工具台**：JSON 校验 / 时间戳 / Base64 / HEX↔RGB / 文本统计
